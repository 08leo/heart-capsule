# 心事胶囊 (Heart Capsule)

> 把心事封存成一颗发光的胶囊，让 AI 给你一封有质感的回响。

**心事胶囊**是一个开源的情绪记录网页应用。写下一句心事，AI 会像一位读过很多书的朋友那样回应你——先接住情绪，再给你一个新角度或一个好问题，偶尔一句短诗，绝不说教、不灌鸡汤。每条心事会根据情绪生成专属颜色与形态的「胶囊」，存进你的时间线。

## ✨ 功能

- **AI 回响** — 温和但不讨好的回应，逐字浮现像一封信
- **情绪胶囊** — 7 种情绪 × 强度决定胶囊的颜色与形态，在夜空中发光
- **情绪星图** — 所有胶囊散布成星座，按日期连成星轨，看见自己的起伏
- **时间胶囊** — 设定开启日期，到期解锁后 AI 写一封「对照信」，告诉你走了多远
- **分享图导出** — 一键生成精美卡片，直接发朋友圈 / 小红书
- **本地存储** — 所有数据只存在你自己的浏览器里，零账号、零上传

## 🚀 使用

在线版：**https://08leo.github.io/heart-capsule/**

默认为演示模式（本地回响文案，无需任何 API）。想接入真实 AI：右上角 ⚙️ → 关闭演示模式 → 填入任意 OpenAI 兼容接口（DeepSeek / 智谱 / OpenAI 等），密钥只保存在你的浏览器。

## 🛠 本地开发

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # 产物在 dist/
```

技术栈：Vite + React，无后端、无数据库。
